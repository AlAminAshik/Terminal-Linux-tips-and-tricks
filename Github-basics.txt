The following codes work for almost all OS. if git is not found, download and install.

> It's better to create a blank repository with a README file from the web and then clone that repository on your local machine.

> Basic 
	> After updating on the local machine, check the status
		git status
	> to prepare file and folders for git upload
		git add .
	> add a comment
		git commit -m 'message'
	> Push the repo
		git push

> To add github SSH on a new machine to easily work with a repo without entering username and pass:
	1. 	ensure git is installed by typing `git --version`
	2.	generate a new keygen on linux: `ssh-keygen -t ed25519 -C "alaminashik890.bd@gmail.com"`
	3.	the key starts with ssh-ed and ends with mail.
	4.	copy the ssh link from the github repo you want to copy.
	5.	clone on the linux machine: `git clone git@github.com:Ongshak-Tech/Steeltech-pipe-QC.git`

> To discard/delete a local change and fetch from online
	> fetch everything
		git fetch --all
	> reset/overwrite all local changes
		git reset --hard origin/main
	> delete untracked file and directories
		git clean -fd
	> if still git status shows any file, manually delete those.
