The followings are optimized for using on linux and Mac. Python3 is usually gets installed with sudo apt upgrade on linux.

> Environment is useful when:
	> permission issue arises on the device while installing packages.
	> keeping a particular package completely separated from other python versions

Normal Environment:
> Downloading and installing environment
		sudo apt install python3-venv
> Create a virtual environment. (Can take some time)
		python3 -m venv myenv
	after creating, activate environment
		source myenv/bin/activate (Linux)
		myenv\Scripts\activate (windows)
	to deactivate the environment
		deactivate

Anaconda environment: This is much more useful but need to install ~950MB of file.
> setup
	Download: `curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh`
	run installer: `bash Miniconda3-latest-MacOSX-arm64.sh`
	restart: source `~/.zshrc`
	create env: `conda create --name ML python=3.11`
	check env list: `conda env list`
> if conda is not initialized in shell by default:
	initiate: `conda init zsh`
	restart: `source ~/.zshrc`
